#Test 
Clicker-Mini-Game (z. B. Keks-Klicker) 🍪
Ein simples Spiel, das auf dem bekannten „Cookie Clicker“-Prinzip basiert.
Design-Idee: Ein zweigeteiltes Layout. Links schwebt ein riesiger, animierter Keks (oder ein anderes Objekt), rechts siehst du deine Statistiken und freischaltbare „Upgrades“.
Der Counter: Der Hauptzähler zeigt deine Gesamtpunkte an. Jeder Klick auf das Objekt erhöht den Zähler. Mit CSS-Effekten (transform: scale) lässt du das Objekt beim Klicken kurz einschrumpfen und wieder wachsen.
